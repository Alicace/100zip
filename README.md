## v0.5.19 新版亮点

- **更完整的压缩体验**：压缩文件名放在“格式与选项”中，扩展名会随 ZIP、7z、TAR 等格式自动变化；支持分卷大小预设与自定义、压缩等级、密码确认和独立输出。
- **批量任务更可靠**：批量解压会为每个压缩包创建独立目录，避免不同任务互相覆盖；批量压缩可以一次生成多份独立压缩文件。
- **包内预览升级**：支持图片、视频、音频、文本、PDF、Word、Excel 和 PowerPoint 等常用文件，并针对 PDF 页面比例、Word 首行和滚动进行了适配。
- **任务中心更清晰**：进度条、速度、剩余时间、状态颜色、失败原因和取消操作更加直观，大文件任务可以持续观察处理状态。
- **移动端适配**：任务列表、预览窗口、底部操作栏和顶部 Tab 针对手机屏幕重新布局，减少横向溢出和内容错位。
- **密码与安全**：支持密码库、按需显示密码、加密多卷包识别和密码错误提示；文件始终在 NAS 本机处理。
- **视觉与交互**：顶部 Tab 增加图标，应用图标采用渐变、圆角、高光和阴影风格，统一桌面与应用内视觉。
- **版本检查**：启动时自动检查项目最新版本；检测到新版本时，版本号旁和设置页都会显示绿色升级按钮，可直接进入 GitHub 下载页。
- **自动命名**：压缩文件名支持自动添加日期或日期时间，批量压缩使用同一任务时间戳。

## 项目介绍

100zip 是一款为飞牛 fnOS NAS 打造的本地压缩与解压应用，目标是让日常的归档、备份、下载包整理和媒体文件管理更简单。

它采用原生 FPK 安装，不依赖 Docker、Node.js 或 Python 运行环境。Go 服务负责任务调度、权限边界和文件处理，内置 7-Zip 引擎负责多格式压缩解压，网页界面则适配桌面和手机浏览器。

所有文件都在 NAS 本机读写，不需要上传到第三方服务。应用通过 fnOS 授权目录控制访问范围，并提供任务记录、失败详情和诊断信息，方便定位密码、权限、缺卷、空间不足或格式不兼容等问题。

当前版本：**v0.5.19**，提供 fnOS x86_64 安装包。

## 核心功能

| 模块 | 详细能力 |
| --- | --- |
| 解压工作台 | 选择压缩包、切换加密多卷包、选择部分文件、指定输出目录、覆盖/跳过策略、自动创建子目录 |
| 压缩工作台 | 选择文件或文件夹、设置压缩文件名、选择 ZIP/7z/TAR 等格式、压缩等级、分卷大小、密码和文件名加密 |
| 批量处理 | 多个压缩包批量解压并自动隔离目录；多个文件或文件夹批量生成相互独立的压缩文件 |
| 多卷支持 | 识别 `.7z.001`、`.zip.001`、`.z01`、`.part1.rar`、`.r00` 等命名方式，缺少卷时给出明确提示 |
| 包内浏览 | 展示目录树、文件名、大小、类型和路径；双击打开预览，支持放大、全屏和滚动 |
| 文件预览 | 图片、视频、音频、TXT/普通文本、PDF、DOC/DOCX、XLS/XLSX、PPT/PPTX 等常用格式 |
| 中文文件名 | 自动识别常见代码页，修复 GBK、Big5、日文等压缩包中的乱码文件名 |
| 密码库 | 保存常用密码、选择密码尝试、显示/隐藏明文、加密包切换后自动重新加载预览 |
| 任务中心 | 排队、并发数设置、实时速度、剩余时间、暂停/取消、重试、历史记录和失败详情 |
| 诊断报告 | 记录任务参数、操作步骤、按钮动作、文件格式、引擎输出和错误上下文，支持导出排查 |
| 移动端 | 手机屏幕下的 Tab、任务卡片、预览区域、操作栏和弹窗自适应布局 |

## 支持格式

### 可解压

`7z` · `ZIP` · `RAR` · `TAR` · `GZ` · `BZ2` · `XZ` · `ZST` · `ISO` · `CAB` · `WIM` · `VHD/VHDX` · `ARJ` · `LZH` · `CPIO` 等。

### 可创建

`7z` · `ZIP` · `TAR` · `tar.gz` · `tar.bz2` · `tar.xz` · `tar.zst`。

RAR 支持稳定解压，但不提供 RAR 创建。具体能力会受压缩格式本身、密码算法和文件系统限制影响。

## 快速上手

### 解压

1. 在“解压”页选择压缩包或多卷压缩包。
2. 如果是加密包，输入密码或从密码库选择。
3. 选择目标目录和覆盖策略。
4. 点击开始，任务会进入任务中心并显示进度。

### 压缩

1. 在“压缩”页添加文件或文件夹。
2. 在“格式与选项”中设置压缩文件名、格式、等级、分卷和密码。
3. 选择目标目录并开始任务。

### 预览

打开压缩包后选择文件即可预览。图片、PDF 和 Office 文档支持放大与滚动；视频和音频使用浏览器内置播放器播放。

## 安装

1. 从 [Releases](https://github.com/Alicace/100zip/releases) 下载最新 `.fpk`。
2. 进入 fnOS「应用中心 → 手动安装」，选择 FPK 文件。
3. 安装完成后，从 fnOS 桌面打开 **100zip**。

也可以通过 NAS 终端安装：

```bash
appcenter-cli stop 100zip || true
appcenter-cli uninstall 100zip || true
appcenter-cli install-fpk /tmp/100zip_0.5.19_x86_64.fpk
appcenter-cli start 100zip
```

## 大文件与性能

- 几十 GB 或上百 GB 任务可以处理，实际耗时取决于 NAS CPU、磁盘读写速度、压缩格式、压缩等级和并发数。
- 应用在任务开始前检查目标目录可用空间，并在任务过程中显示速度和进度。
- 7z 高压缩等级更节省空间，但会消耗更多 CPU；ZIP 通常兼容性更好、速度更快。
- 建议机械硬盘使用较低并发，SSD 或高性能 NAS 可以适当提高并发数。

## 隐私与安全

- 文件处理在 NAS 本机完成，不上传文件内容。
- 只访问用户在 fnOS 中授权的目录。
- 密码不会拼接到外部命令行参数中。
- 诊断报告用于排错时应注意其中可能包含文件名、路径和任务参数，分享前请先检查内容。
